# sys.checksum component (Stage 3 proof of concept)

This is a **WebAssembly Component Model** build of `sys.checksum`, separate
from the existing `cdylib` plugin in the parent directory.

It exists to validate the polyglot/sandboxed trait story end-to-end:
1. Implements the WIT contract at [`../checksum.wit`](../checksum.wit) (generated by `gen-wit`).
2. Compiles to a Wasm component via `cargo component build --release`.
3. Transpiles to browser-loadable ESM via `jco transpile`.
4. The transpiled output lives under `static/components/sys-checksum/` and is
   served by the existing static handler.

## Build

```bash
# 1. Build the component
cd traits/sys/checksum-component
cargo component build --release
# → target/wasm32-wasip1/release/sys_checksum_component.wasm

# 2. Transpile to ESM (browser-loadable)
jco transpile target/wasm32-wasip1/release/sys_checksum_component.wasm \
    -o ../../www/static/components/sys-checksum --no-typescript
```

The transpiled output imports `@bytecodealliance/preview2-shim` (WASI preview2
JS shim). The demo page resolves it via an `<script type="importmap">` pointing
to `https://esm.sh/@bytecodealliance/preview2-shim`.

## Demo

Once the kernel is running (`./target/release/traits serve`), open:
- <http://localhost:8092/components-demo>

Or in any JS console served by the kernel:

```js
const { instantiate } = await import('/components/sys-checksum/sys_checksum_component.js');
const inst = await instantiate(async (path) => WebAssembly.compileStreaming(fetch('/components/sys-checksum/' + path)));
console.log(inst.checksum.checksum('hash', 'hello world'));
```
